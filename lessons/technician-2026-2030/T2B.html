Repeaters have a few features that trip up new hams: tones, squelch, offsets and digital talkgroups. This lesson covers how they work and how to fix the usual "I can hear it but can't get in" problem. It ends with Q signals.

Squelch and tones

Squelch mutes the receiver's audio when no signal is present, so you don't hear constant hiss.

Many repeaters only respond if your transmission carries a special tone, so they ignore stray signals.

  • CTCSS is a sub-audible tone sent along with your voice that opens the repeater's squelch. You'll see it called "PL tone" in many radios.
  • DCS is a digital version of the same idea, using a code instead of a tone.
  • DTMF uses two tones at once. It's the beeps from a phone keypad, used to send commands to a repeater.

Can hear it, can't get in

If you hear the repeater but it won't respond to you, it could be any of these: the wrong offset, the wrong CTCSS tone, or the wrong DCS code. Check your radio's settings against the repeater's listing.

The reverse button swaps your radio to listen on the repeater's input frequency. That lets you hear whether the other station is close enough to talk to directly on simplex.

If your audio drops out on voice peaks, you're talking too loudly (or too close to the microphone). Back off a bit.

Simplex channels and sharing

Band plans set aside simplex channels so stations within range of each other can talk without tying up a repeater. If two stations interfere with each other, nobody owns a frequency; they should work it out between them (negotiate).

Linked and digital repeaters

In a linked repeater network, a signal received by one repeater is transmitted by every repeater in the network. That lets you talk across a state or the world.

On DMR (a popular digital voice system):

  • A talkgroup is an identifier that organizes traffic, so people who want a particular group hear it and aren't bothered by everything else. You join one by programming its ID into your radio.
  • A color code is an access code you must program into your radio to use a specific repeater. It's like CTCSS for DMR.

Q signals

Three-letter shorthand from the Morse code days, still used by voice:

Q signalMeaning
QRMInterference from other stations (man-made)
QRNNatural noise, like static from lightning
QSYChanging frequency
QTHLocation
QSLI acknowledge receipt

Memory hook: QRM = "man-made" mess, QRN = "natural."

Key facts

  • Squelch mutes the audio with no signal. CTCSS = a sub-audible tone. DTMF = two simultaneous tones.
  • Can't access a repeater you can hear: offset, CTCSS or DCS. All are possible causes.
  • Reverse = listen on the repeater's input.
  • Audio dropping on peaks = talking too loudly.
  • Interference between two stations: negotiate.
  • Linked network: everything is retransmitted by all repeaters.
  • DMR talkgroup: program its ID. Color code: an access code for a repeater.
  • QRM = interference; QSY = changing frequency.
