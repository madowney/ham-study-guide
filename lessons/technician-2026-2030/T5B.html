Radio deals with tiny and huge numbers: microvolts of signal and megahertz of frequency. Metric prefixes make those manageable, and decibels make comparing power easy. This is a math lesson, but a gentle one.

Metric prefixes

PrefixMeansExample
pico (p)one-trillionthpicofarad (capacitors)
micro (µ)one-millionth1 microvolt = 0.000001 volt
milli (m)one-thousandth1 milliamp = 0.001 amp
kilo (k)thousand1 kilovolt = 1000 volts
mega (M)million1 MHz = 1,000,000 Hz
giga (G)billion1 GHz = 1000 MHz

Each step on the ladder (pico, nano, micro, milli, base unit, kilo, mega, giga) is a factor of 1000. Moving one step means moving the decimal point three places.

Converting, step by step

  • Going to a smaller unit, the number gets bigger: 1.5 A = 1500 mA. 3.525 MHz = 3525 kHz.
  • Going to a bigger unit, the number gets smaller: 3000 mA = 3 A. 500 mW = 0.5 W. 28,400 kHz = 28.400 MHz. 2425 MHz = 2.425 GHz.
  • 1,500,000 Hz = 1500 kHz (= 1.5 MHz).
  • 1,000,000 picofarads = 1 microfarad. That's two steps, pico to nano to micro: 1,000,000 pF = 1000 nF = 1 µF.

Sanity check: the answer should be "a bigger number of the smaller thing" or "a smaller number of the bigger thing." If both got bigger, you went the wrong way.

Decibels (dB)

Decibels describe power changes as ratios. You need only three facts:

Power changeDecibelsExam example
Doubled (×2)+3 dB5 W → 10 W
Quartered (÷4)−6 dB (two halvings: −3, −3)12 W → 3 W
×10+10 dB20 W → 200 W

Halving is −3 dB, so a quarter is two halvings, or −6 dB. Likewise ×4 is +6 dB and ×100 is +20 dB.

Key facts

  • Each prefix step = ×1000, or three decimal places.
  • 1.5 A = 1500 mA · 3000 mA = 3 A · 500 mW = 0.5 W · 1 kV = 1000 V · 1 µV = one-millionth of a volt.
  • 1,500,000 Hz = 1500 kHz · 3.525 MHz = 3525 kHz · 28,400 kHz = 28.4 MHz · 2425 MHz = 2.425 GHz.
  • 1,000,000 pF = 1 µF.
  • ×2 = +3 dB · ÷4 = −6 dB · ×10 = +10 dB.
