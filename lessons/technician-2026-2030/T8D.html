A lot of ham radio today is digital: text, data, position reports and digital voice. This lesson covers the names you need to recognize and what each one does.

The digital modes

NameWhat it is
CWMorse code. Technically the first digital mode.
FT8A digital mode built to work at very low signal-to-noise, decoding signals too weak to hear. It's part of the WSJT-X software suite, which also supports moonbounce (EME), meteor scatter and weak-signal beacons.
PSKPhase Shift Keying, a keyboard-to-keyboard text mode
Packet radioData sent in packets, each with a header (including the destination call sign), a checksum to detect errors, and automatic repeat requests if something's wrong
APRSAutomatic Packet Reporting System: sends GPS position, text messages and weather data, typically shown as stations on a live map for real-time tactical use
DMRDigital voice that time-shares two voice signals on one 12.5 kHz repeater channel
Mesh networkA ham data network built from commercial Wi-Fi gear with modified firmware

Packet radio, Wi-Fi (IEEE 802.11) and FT8 are all digital modes.

Error correction: ARQ

ARQ (Automatic Repeat reQuest) is error correction where the receiving station detects an error and asks for that part to be sent again.

Television

NTSC is the old analog fast-scan color TV standard, the same as broadcast TV used to be. Hams can send it on UHF.

Key facts

  • CW = Morse code. PSK = phase shift keying.
  • FT8 = low signal-to-noise digital. WSJT-X covers EME, meteor scatter and beacons.
  • Packet: header, checksum and automatic repeat. ARQ = the receiver requests a retransmission.
  • APRS: GPS, text and weather, shown on a map.
  • DMR: two voice signals time-shared on 12.5 kHz.
  • Mesh: modified commercial Wi-Fi. NTSC: analog fast-scan color TV.
