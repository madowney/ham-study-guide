This lesson covers amplifiers, oscillators and a little digital logic: the building blocks inside every transmitter.

Amplifier classes

Amplifier classes differ in how much of each cycle the transistor or tube conducts. More conduction means a cleaner copy of the input; less means better efficiency.

ClassConductsLinear?Efficiency
A100% of the timeYesLowest
ABMore than 50%, less than 100%YesMedium
B50%Yes, in pairsHigher
CLess than 50%NoHighest
  • A linear amplifier is one whose output preserves the input waveform. SSB and AM need one, because their amplitude carries the voice.
  • Class C distorts the amplitude, so it's only right for modes with constant amplitude. For a modulated signal, that's FM.
  • Efficiency = RF output power ÷ DC input power.
  • Neutralizing an amplifier means eliminating self-oscillation, where it starts generating its own signal.

Oscillators

An oscillator creates a signal from nothing but DC power. A sine-wave oscillator is a filter and an amplifier in a feedback loop: the amplifier keeps the signal going, and the filter picks the frequency.

In an LC oscillator, the frequency is set by the inductance and capacitance in the tank circuit. (Remember resonance from the reactance lesson.)

Digital logic

  • A two-input AND gate: the output is high only when both inputs are high.
  • A 3-bit counter has 2 × 2 × 2 = 8 states, from 000 to 111.
  • A shift register is a clocked array of circuits that passes data in steps along the array, like a bucket brigade.

Key facts

  • Class A conducts 100% of the time. Class C has the highest efficiency and is OK for FM.
  • Linear amplifier: the output preserves the input waveform.
  • Efficiency = RF out ÷ DC in. Neutralizing stops self-oscillation.
  • Sine-wave oscillator: a filter and an amplifier in a feedback loop. LC oscillator frequency: set by L and C in the tank.
  • AND: high only if both inputs are high. A 3-bit counter has 8 states. Shift register: passes data step by step.
